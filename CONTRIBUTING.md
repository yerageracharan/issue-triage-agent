# Contributing

1. Create a virtual environment and install the project with `python -m pip install -e ".[test]"`.
2. Add or update a focused test for your change.
3. Run `python -m pytest`.
4. Keep GitHub operations read-only. Do not add automatic comments, labels, assignments, or issue state changes without a separately reviewed design and explicit opt-in.
5. Document new heuristics and their limitations in the README.

Please keep the default workflow free of paid APIs and ensure all core features work without a language model.
