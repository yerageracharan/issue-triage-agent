# Security Policy

Please do not report sensitive vulnerabilities in public GitHub issues. Use the repository owner's private vulnerability reporting channel where available.

The Issue Triage Agent is a read-only client. It does not request or use GitHub write permissions. Keep personal access tokens outside source control and grant only the minimum read permissions required.

The optional local-model adapter sends issue text to the endpoint configured by the operator. Use it only when that endpoint is approved to process the repository's issue content.
